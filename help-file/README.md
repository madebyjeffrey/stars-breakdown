# Exported Stars! help file

This directory preserves the supplied HTML export of the Stars! Player's Guide.
The reverse-engineering-oriented reading guide is
[`analysis/reconstruction/help-file.md`](../analysis/reconstruction/help-file.md).

Useful entry points in the export:

- [`index.html`](out/index.html) — contents and topic index
- [`keywords.html`](out/keywords.html) — keyword-to-topic index
- [`contexts.html`](out/contexts.html) — numeric help-context map
- [`t10002.html`](out/t10002.html) — “The Guts” advanced-rules index

The HTML pages are the semantic export; the `bm*.bmp` files are part of the
evidence. In particular, the technology tables are screenshots in the BMPs,
not structured HTML data, so values transcribed from them should retain the
bitmap filename and a confidence/provenance note.
