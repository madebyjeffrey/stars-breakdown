## Whole-file accounting

Every file byte belongs to exactly one range in `layout.json:file_regions`; there are no unexplained nonzero gaps. Outside segments/resources/tables, remaining inter-region gaps are verified zero padding. The only trailing payload is the identified NB09 debug block and its trailer. Classification identifies storage roles, not the meaning of every instruction or data byte.

The DOS entry at file offset `0x200` executes a near CALL to `0x256`. That pops the message address into DX, sets DS=CS, uses DOS interrupt 21h/AH=09 to print “This program requires Microsoft Windows.”, and exits via AX=4C01h. No DOS relocations are present. DOS header size/page fields are retained as original metadata; their declared load extent overlaps NE metadata and must not be interpreted as a separate non-overlapping game overlay.

## Validation evidence

- Tests partition the entire file, verify relocation-chain bounds and disjoint patch sites, and check every applied address fixup against its target.
- `ReadIniSettings` at `0001:17cf` contains `9a ec 2a 41 09`: its selector word is a relocation-chain link. The internal fixup changes this to synthetic `9a ec 2a 28 10`, resolving the call to `0005:2aec`, the debug-record address of `FSerialAndEnvFromSz`.
- The USER ordinal 1 record at file offset 118825 chains segment 5 offsets 29481 → 16395 → FFFF. Both sites resolve to synthetic `8020:0001`, annotated `MessageBox`.
- The About dialog caption and 10 controls decode correctly. Every grouped icon/cursor points to an existing image resource; every dialog static-icon name resolves after case normalization.
- Segments 5, 14, and 34 each have one final zero-filled byte; segment 37 has 17,236 zero-filled bytes. Translation and image checks explicitly cover these boundaries.
- Data mapping independently agrees with `SetFileSeeds`: CodeView segment 69 offsets 0 and 4 map to DGROUP offsets 0x2272 and 0x2276, exactly the stores in the machine code for `lFileSeed1` and `lFileSeed2`. Both globals are in zero-fill.
- These are byte-level and reference-implementation checks. No native Windows execution or independent decompiler import has been performed yet.
